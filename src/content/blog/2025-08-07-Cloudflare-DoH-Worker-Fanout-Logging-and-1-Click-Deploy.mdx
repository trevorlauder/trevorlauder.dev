Back in 2021 I wrote about keeping our family's devices on DNS over HTTPS even when networks tried to block it. That stopgap proxied to a single provider. This follow-up goes further with a Cloudflare Worker that fans out DoH requests to multiple providers in parallel, combines their filtering decisions, and optionally sends structured logs to Grafana Loki, with a 1-click deploy.

- [Project on GitHub](https://github.com/trevorlauder/cloudflare-doh-worker)
- [Avoiding DNS over HTTPS Detection and Blocking](/blog/home-projects/2021/09/25/avoiding-doh-detection-and-blocking/) (2021 background post)

## What's new

- Multi-provider fan-out, querying any number of DoH providers in parallel
- Combine filtering so if any provider blocks a domain, the worker blocks it (while still letting you choose a “main” provider to source the final response)
- Per-endpoint config with multiple paths, each with its own provider set and headers
- NextDNS headers for device name/model and profile path per endpoint
- Logging to Grafana Loki for your own dashboards and alerts
- One-click Deploy to Cloudflare, then tweak `wrangler.toml` and `src/config.js`
- Local/dev via Docker + workerd
